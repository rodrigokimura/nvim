# Neovim Config

Personal [Neovim](https://neovim.io/) configuration and plugins.

## Structure

- `init.lua` / `init.vim` — entry point
- `lua/` — Lua modules
- `after/` — Lazy-loaded overrides

## Features

- LSP support
- Treesitter syntax highlighting
- Fuzzy finder and file explorer
- Custom keymaps and autocmds
